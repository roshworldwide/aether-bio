# aether-bio

Cinematic project-showcase UI. Atmosphere and fluid rendering engine in React.

## Why this exists

A portfolio-style showcase deserves more than a static grid. aether-bio is an experiment in a cinematic, motion-heavy project browser — an atmosphere engine, fluid background, and glass UI built to make browsing projects feel like a designed environment.

## What it does

- Renders an animated atmosphere and fluid background in React.
- Presents projects through a cinematic, glass-panel interface.
- Backs content with a small API and a Prisma data layer.

## Stack

Next.js · React · Prisma · custom rendering components

## Status

Experimental. Built as a UI exploration; the "physics engine" framing in the original description overstated what is a motion and rendering experiment.
